# Global Superstore Sales Analytics Dashboard

## 🔗 Live Dashboard
👉 [View Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/gaural.rathod/viz/Tableau-Sales_17789505733910/GlobalSuperstoreAnalyticsDashboard?publish=yes)

## 📊 Project Overview
A data visualisation project exploring sales profitability, discount-profit correlation and shipping cost analysis using Tableau's interactive filtering and view coordination features.

## 📁 Dataset
- **Name:** Global Superstore Dataset
- **Source:** [Kaggle](https://www.kaggle.com/datasets/fatihilhan/global-superstore-dataset)
- **Size:** 51,290 rows × 27 columns
- **Period:** 2011–2014
- **Markets:** US, EU, LATAM, Africa, APAC, EMEA, Canada
- **Segments:** Consumer, Corporate, Home Office

  ### 📜 Credits
- **Dataset:** Global Superstore Dataset by Fatihilhan on Kaggle

## 👤 Persona
**Alex Morgan** — Regional Sales Director at a global 
retail corporation, responsible for monitoring and 
improving profitability across international markets 
and customer segments.

## ❓ Questions Answered
| # | Question | Type |
|---|---|---|
| SQ1 | Which product sub-categories are the most and least profitable? | Simple — Ranking |
| SQ2 | Does higher discounting reduce profit? | Simple — Correlation |
| SQ3 | How have sales and profit trended by customer segment? | Simple — Time Series |
| CQ | For a selected market and segment, which sub-categories have high sales but low profit — and does shipping mode explain this gap? | Complex |

## 🛠️ Tools Used
- Tableau Desktop

## ✨ Dashboard Features
- Interactive Market and Segment filter dropdowns
- Brushing interaction — click sub-category dot to 
  filter linked shipping cost bar chart
- Tableau Story with 4 annotated story points
- Dual-axis line chart for sales vs profit trends

## 🔍 Key Findings
- **Tables** sub-category is consistently loss-making 
  across markets (-$64K total profit)
- Heavy discounting (>40%) almost always results in 
  loss-making orders (p < 0.0001, R² = 0.10)
- **Consumer** segment leads in both Sales and Profit
- **Same Day** shipping is the primary cost driver reducing profit margins in US Corporate segment
